# 02: 真实局域网 TCP 可靠通道

**What to build:** 把切片 01 的环回换成**两台真实设备之间的 TCP 连接**，同一个合成画面跨设备流过去并渲染。用户价值：第一次真正在手机上点"开始"，平板上看到画面动起来（仍是合成画面，不是真屏幕）。
**Blocked by:** 01（环回垂直切片）
**Status:** ready-for-agent

- [ ] 实现 TCP 版 `Transport`：监听端与连接端两个方向，服务端口可配置
- [ ] 可靠通道分帧：长度前缀解决粘包/半包，超长包被拒绝而不是撑爆内存
- [ ] 连接生命周期：连接建立、正常关闭、对端异常断开、心跳超时判定为断开，状态变化回调 UI
- [ ] 断线后 UI 有明确状态（已断开 + 可重连），不静默假死
- [ ] 集成测试用 localhost 真实 socket：粘包、半包、对端断开、心跳超时四条路径均有覆盖；端口用 `0` 由系统分配，禁止硬编码
- [ ] 手工验收：两台真机（或真机+模拟器）同 Wi-Fi 下，一端开始发送、另一端填 `IP:端口` 连接，能看到合成画面动起来
- [ ] 发送端在投屏期间持有 Wi-Fi 锁/前台服务，避免息屏后网络被挂起
- [ ] 明确 v1 的已知限制并在 UI 上说明：媒体暂时跑在 TCP 上，延迟优化在切片 07
