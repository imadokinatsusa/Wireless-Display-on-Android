# 09: 设备发现与手动连接入口

**What to build:** 同一局域网内自动列出可投屏的设备（名字、型号、角色），点一下就能连；自动发现不可用时（网络禁 mDNS、隔离 AP）用手输 `IP:端口` 兜底。用户价值：不用每次问"手机 IP 是多少"。
**Blocked by:** 03（会话握手与能力协商）
**Status:** ready-for-agent

- [ ] `NsdManager` 服务注册（接收端侧广播）与发现（发送端侧浏览），服务类型 `_whalecast._tcp`
- [ ] 广播内容含设备名、设备 ID、角色、能力摘要（分辨率/编码档位），供列表直接展示可用性
- [ ] 设备列表 UI：在线/离线状态、角色标识、下拉刷新、点按连接、连接失败有具体原因
- [ ] 手动 `IP:端口` 输入作为兜底入口，与自动发现汇入**同一个连接编排入口**（不写两份连接逻辑）
- [ ] 手动连接成功后设备被记住，下次出现在列表里可直接点
- [ ] 发现不到设备时给出可操作的排查提示（同一 Wi-Fi、AP 隔离、防火墙、手动输入）
- [ ] 发现流程的纯逻辑部分有单测：设备列表去重与更新、服务消失时置为离线、手动与自动路径汇入同一入口
- [ ] 手工验收：两台设备同 Wi-Fi 下打开即互相看见；关闭 mDNS/用隔离网络时手动 IP 仍可连
