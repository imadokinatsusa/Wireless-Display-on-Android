# 13: 本地录制与截图的产品化体验

**What to build:** 把切片 04 预留的编码出口做成完整可用的功能：录制中可暂停/停止、显示时长与文件大小、结束后落入系统相册；截图一键保存并可直接分享；长时间录制与存储不足有稳妥处理。用户价值：演示、游戏录像、报错截图都能顺手留下。
**Blocked by:** 04（发送端真实采集与硬件编码）
**Status:** ready-for-agent

- [ ] 录制控制：开始、暂停/继续、停止，界面显示时长、文件大小、当前码率
- [ ] 录制与投屏可同时进行，互不影响（录制不额外降低投屏帧率）
- [ ] 落盘位置：通过 `MediaStore` 写入系统相册/影片目录，结束后立即可在相册看到
- [ ] 截图：一键抓取当前帧，保存到相册并可直接调起分享
- [ ] 长时间录制稳定性：连续录制 30 分钟不丢帧崩溃，文件可正常播放且音画同步（若切片 08 已完成）
- [ ] 存储不足与写入失败的降级：明确提示、停止录制而不损坏已录文件、不崩溃
- [ ] 息屏/切后台/来电话中断录制时的行为明确（继续、暂停或安全收尾），文件不损坏
- [ ] 手工验收：录制 10 分钟投屏视频并在相册播放正常；截图与分享链路可用；拔卡/存储满时行为正确
