# 05: 体验与诊断 —— 三屏 UI、诊断行、本地双指缩放

**What to build:** 把 03/04 的能力包成主人能天天用的样子：首页选角色、发送端扫设备、接收端全屏看画面并能双指缩放；所有异常都在诊断行可见（真机没有 adb）。
**Blocked by:** 04
**Status:** ready-for-agent

- [ ] 首页：两个入口（发送端 / 接收端）+ 版本与网络状态
- [ ] 发送端：自动发现设备列表（设备名 + 地址 + 连接码），点选即投；扫描用 `BeaconScanner` 并**定期清理过期设备**
- [ ] 接收端：连接码大字展示（供对方核对）+ 连接状态 + 全屏画面
- [ ] 本地缩放：双指捏合与比例输入，全部经由 `ViewTransform` 状态（缩放/平移），不藏在 View 内部；双击复位
- [ ] 诊断行（完整版）：状态、分辨率、帧率、端到端延迟、丢包率、码率、抖动缓冲、A-V 偏差
- [ ] 停止投屏：通知栏动作 + 界面按钮，服务与采集一并释放（不留常驻通知）
- [ ] 权限引导：通知权限、录音权限、屏幕授权各自的失败提示与重试入口
- [ ] 资源纪律：退出界面/停止会话后不残留前台服务、采集、连接
- [ ] 手工验收：串起来完整走一遍（发现 → 投屏 → 缩放 → 停止 → 再投）
