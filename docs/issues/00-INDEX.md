## 依赖图

```
01 骨架切换（mirror 命名 + WebRTC 依赖 + 删旧协议）★frontier
└─▶ 02 信令通道（core:signal，纯 JVM）
    ├─▶ 03 视频端到端（采集发布 → 解码渲染）★核心
    │   └─▶ 04 音频端到端（内录 → 音频轨 → 播放）
    │       └─▶ 05 体验与诊断（三屏 UI / 诊断行 / 本地缩放）
    │           └─▶ 06 真机验收（延迟 / A-V / 10 分钟）
    └─▶ (03 与 02 完成后即可并行验证接收端渲染)
```

- ★ = 可立即开始的前沿工单。
- 03 是 M1 的 tracer bullet：它一次性打通"两台手机、一条会话、一块画面"。

## 里程碑

**M1 = 03 + 04 同时满足验收标准**（1080p@30fps、≤150ms、A-V ≤100ms、10 分钟不崩）。
05/06 是把 M1 变成"主人能天天用"的收尾。
